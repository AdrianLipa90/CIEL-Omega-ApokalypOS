# 03. Grammar as Local Gauge

## Principle

Grammar is local gauge; context is boundary condition; invariant is meaning.

For language \(l\):

\[
\mathcal{A}_{\Omega}^{(l)}=\mathcal{A}_{core}+\mathcal{A}_{gram}^{(l)}+\mathcal{A}_{context}
\]

## Language gauge profile

A language profile \(\Gamma_l\) contains:

- POS inventory mapping
- dependency-role mapping
- word order tendency
- case marking
- aspect/tense encoding
- polarity and negation scope
- evidentiality markers
- honorificity/social-indexing markers
- topic/focus strategy
- cross-linguistic invariant mapping

## Cross-linguistic compatibility

For sentences \(S_{l_1}\) and \(S_{l_2}\):

\[
D_{cross}(l_1,l_2)=d_{\Omega}(\hat{\mathfrak{S}}_{l_1}(S_{l_1}),\hat{\mathfrak{S}}_{l_2}(S_{l_2}))+\lambda|Hol^{(l_1)}-Hol^{(l_2)}|
\]

Compatibility:

\[
D_{cross}<\epsilon_{cross}
\]

provided:

\[
I_{sem}^{(l_1)}\cong I_{sem}^{(l_2)}
\]

## Practical implication

Translation should preserve invariants, not word surfaces. A high-quality CIEL translation preserves:

1. predicate-argument core,
2. roles,
3. polarity,
4. modality,
5. tense/aspect where semantically relevant,
6. antonym phase constraints,
7. MAS affect/outcome vector,
8. consensus holonomy where available.
