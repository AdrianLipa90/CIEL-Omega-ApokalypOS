# 13. Functional Words, Duals and Polyfunctional Operators

Some words are small semantic machines.

## `have / mieć`

`have` is not one relation. It is a family of typed relations:

```text
Have(possessor, possessed)
HasPart(whole, part)
HasProperty(entity, property)
HasState(entity, state)
```

## `inside / contain`

Dual pair:

```text
Inside(x,y) ⇔ Contains(y,x)
```

The same invariant may surface in opposite grammatical orientation.

## `how / jak`

`how/jak` is polyfunctional:

```text
How(T)        -> ask(Manner(T))
Like(x,y)     -> Sim(x,y)
As(x,y)       -> MapPattern(y -> x)
```

## Rule

Do not encode functional words as normal concept cards unless they carry independent semantic body behavior.

```text
Nouns are masses.
Verbs are transformations.
Prepositions are geometry.
Conjunctions glue spaces.
Particles shift phase.
Adverbs modify operators.
Functional words are machines.
```
