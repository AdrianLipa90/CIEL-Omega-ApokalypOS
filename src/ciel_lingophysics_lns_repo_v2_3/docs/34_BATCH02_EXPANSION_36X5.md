# CIELingo v1.8 — Batch02 Expansion 36×5

Batch02 adds 36 multilingual CONCEPT_CARD seeds across five languages: PL, EN, DE, FR, ES.

Theme: body, cognition, social relations, places, exchange, law/work/money, and language/sound/story.

## Principle

Batch02 is not a dictionary import. It is a hand-curated seed layer. Each concept card is a semantic mass / attractor with language panels and operator hooks.

```text
Concept cards = masses / attractors
Operator hooks = forces / functions
Grammar vectors = local gauge coordinates
Relations = draft graph edges
```
