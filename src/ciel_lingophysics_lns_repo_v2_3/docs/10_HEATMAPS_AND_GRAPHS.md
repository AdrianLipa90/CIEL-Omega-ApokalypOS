# Comparative Heatmaps and Graphs

The v0.7 repository contains comparative matrices and generated visualizations.

## Matrices

- `data/heatmaps/grammar_operator_distance.csv` compares local grammar gauges.
- `data/heatmaps/cross_language_semantic_similarity.csv` gives seed semantic similarity for the shared concept card.
- `data/heatmaps/water_semantic_affective_gradient.csv` maps the water attractor across life, flow, danger, cleansing and dryness-antiphase axes.

## Graph

- `data/graphs/water_concept_graph.json` is the machine-readable graph.
- `data/graphs/water_concept_graph.graphml` can be opened by graph tools.
- `outputs/graphs/water_concept_graph.png` is the generated preview.

## Rule

Heatmaps reveal distance and curvature; graphs reveal relational topology. Both are required because similar values in a matrix may still hide different path operators.
