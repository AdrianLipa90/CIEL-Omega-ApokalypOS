# Grammar Mathematization Per Language

Grammar is represented as a local gauge connection, not as the universal meaning itself.

```text
A_Ω^(l) = A_core + A_gram^(l) + A_context + A_memory
```

Each language profile contains a grammar vector over axes:

```text
inflection, word_order_fixedness, topic_focus, particle_density, case_marking, agreement, honorificity, context_reliance
```

The vector is not a final linguistic truth. It is a calibration seed. The curvature estimate is the local spread of the vector and acts as a warning: high curvature means grammar strongly changes the path to the invariant.

## Required per-language objects

- surface lemma and script
- parts of speech mapping
- sentence role mapping
- grammar operators
- inflection or particle strategy
- synonym and antonym phase constraints
- context examples
- cross-language invariant mapping
