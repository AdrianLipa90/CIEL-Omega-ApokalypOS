# CIELingo v2.3 — Dialect and Fine-Tuning Adapters

Dialects and language variants are local adapter layers. They must not overwrite canonical language profiles. Adapter levels: L0 lexical, L1 morphological, L2 syntax, L3 pragmatic/register, L4 separate language candidate. Fine-tune adapter layers and auxiliary classifiers first. GGUF or LLM verdicts remain advisory.
