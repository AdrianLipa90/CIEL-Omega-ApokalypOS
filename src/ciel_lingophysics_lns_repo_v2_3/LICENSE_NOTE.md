# Data and Licensing Note

This repository contains only handcrafted seed examples and original CIEL-LNS/Ω specification material.

Do not copy or redistribute proprietary dictionary entries from PWN, Oxford, or other publishers unless the project has a valid license that permits storage, processing, redistribution and derivative machine-readable use.

Recommended data policy:

1. Keep external lexical sources in `data/external/`, excluded from Git by default.
2. Store source metadata and license files with every import.
3. Store normalized derived features only when the license allows it.
4. Separate proprietary adapters from open reference data.
5. For publication/commercial deployment, run a license audit before bundling any lexical database.

Preferred open bootstrap candidates:

- Open English WordNet, where compatible with project use.
- Princeton WordNet, where compatible with project use.
- plWordNet/Słowosieć, where compatible with project use.
- Universal Dependencies treebanks for grammar and dependency patterns, where compatible with project use.
- Wiktionary dumps, with strict attribution/share-alike handling when required.
